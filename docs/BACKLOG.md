- **Accettazione:** (1) da UI creo due progetti con nomi diversi e formato Standard; (2) dopo riavvio entrambi sono visibili e apribili; (3) dati/stato del primo non mutano aprendo il secondo; (4) un progetto nuovo mostra chiaramente «da costruire», senza lista o falsa validità; (5) un errore di persistenza è visibile, non produce una conferma di salvataggio fittizia.
- **Verifica eseguita il 23-10-2026:** `npm test` (2 test sull'archivio SQLite), `npm run typecheck`, `npm run build` e `npm run test:e2e` superati su Windows con Node 24; `npm ci`, stessi controlli e percorso Electron grafico superati su Ubuntu 24.04 in WSL con Node 24 e `xvfb-run`. - **Evidenza:** implementati UI React, processo Electron, bridge IPC limitato e archivio SQLite locale in `src/`; progetti Standard nuovi mostrano «Da costruire» e lista assente.
